# Contributing

- Fork the repo and open a pull request with a short description of the change.
- Run `npm run type-check`, `npm run lint` and `npm test` before you push.
- Keep PFControl attribution and the AGPL license intact (see `NOTICE.md`).

Bugs that also exist upstream are best reported to PFControl too: https://github.com/cephie-studios/pfcontrol-2
